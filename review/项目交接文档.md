## 1. 项目概述

**FocusGuard** - 专注环境助手 App

- **定位**：基于手机传感器的专注与环境监测 App，帮助用户在学习、工作场景中记录环境噪声、光照、手机移动
- **技术栈**：Kotlin + Jetpack Compose + Room + Hilt + Coroutines/Flow
- **目标**：日常可用 + 面试展示，冲击 1w+ 月薪 Android 岗位

## 3. 项目架构

### 目录结构

```
app/src/main/java/com/ywb/focusguard/
├── FocusGuardApplication.kt      # Hilt 入口
├── MainActivity.kt               # 唯一 Activity
├── data/
│   ├── local/                    # Room 层
│   │   ├── database/             # 数据库
│   │   ├── dao/                  # DAO 接口
│   │   ├── entity/               # 实体类
│   │   └── mapper/               # Entity ↔ Domain 映射
│   ├── repository/               # Repository 实现
│   └── sensor/                   # 传感器数据源
├── domain/
│   ├── model/                    # 领域模型
│   └── analyzer/                 # 业务分析器
├── di/                           # Hilt Module
├── service/                      # 前台服务、广播接收器
└── ui/
    ├── navigation/               # 导航路由
    ├── screen/                   # Compose 页面
    ├── state/                    # UiState
    └── viewmodel/                # ViewModel
```

### 核心设计决策

1. **Repository 接口抽象**：ViewModel 依赖接口，不依赖 Room 具体实现
2. **Service 独立运行**：前台服务内部维护计时，不依赖 ViewModel
3. **SharedFlow 通信**：通知栏事件通过 Flow 传递，生命周期安全
4. **传感器 callbackFlow**：自动处理传感器注销，避免内存泄漏

## 4. 关键文件说明

| 文件 | 职责 |
|------|------|
| `SessionViewModel.kt` | 专注状态机，管理计时、采样、服务启动 |
| `FocusMonitorService.kt` | 前台服务，独立计时，更新通知 |
| `SessionStateHolder.kt` | ViewModel 与 Service 之间的状态共享 |
| `SessionActionReceiver.kt` | 接收通知栏按钮点击，发送事件 |
| `NoiseSensorDataSource.kt` | AudioRecord 噪声采集 |
| `FocusRepositoryImpl.kt` | 会话生命周期、采样保存、评分计算 |

## 5. 构建与运行

```bash

export JAVA_HOME='E:/jdk21'

# 构建 Debug APK
cd E:/Users/YWB/AndroidStudioProjects/FocusGuard
./gradlew.bat :app:assembleDebug
```

**环境注意**：
- 本机 JAVA_HOME 默认指向 JDK 17，但 Gradle 需要 JDK 21
- 本机有 `E:\jdk21` 可用
